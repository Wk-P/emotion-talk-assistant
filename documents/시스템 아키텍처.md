# 시스템 아키텍처

이 시스템은 **사용자 – 프런트엔드 – 백엔드**가 위아래로 연결되고, 백엔드가 양옆의 **인공지능**과 **데이터 관리**와 각각 주고받는 구조입니다. 사용자는 프런트엔드만 직접 사용하며, 인공지능과 데이터베이스에는 항상 백엔드를 거쳐 접근합니다.

## 프런트엔드

사용자가 직접 보고 사용하는 웹 화면입니다. Vue 3와 TypeScript로 개발했고, Vite로 빌드하며, 화면 이동은 Vue Router, 상태 관리는 Pinia가 담당합니다. vue-i18n으로 중국어와 한국어를 지원하며, Cloudflare Workers에 배포되어 있습니다.

사용자는 이곳에서 **언어를 선택**하고, **대화를 시작**하며, **성찰일지**를 작성하고, 저장한 **기록을 조회**합니다.

## 백엔드

프런트엔드의 요청을 받아 처리하는 서버입니다. Python 3.12와 FastAPI로 개발했고 Uvicorn으로 실행합니다. 데이터베이스 연결은 SQLAlchemy 2(비동기), 데이터 형식 검증은 Pydantic을 사용합니다. 로그인은 JWT로 인증하고, 민감한 기록은 Fernet으로 암호화하며, Docker로 배포합니다.

주요 역할은 다음과 같습니다.

- **사용자·세션 관리**
- **대화 목적·상태 및 활동 경로 관리**
- **맥락 조회·프롬프트 구성**: 대화 맥락을 불러와 AI에게 보낼 안내문을 만듭니다.
- **AI API 연동·응답 처리**
- **활동·기록·사용로그 관리**

## 인공지능

백엔드가 호출하는 AI 서비스입니다. OpenAI API를 사용하며, 응답은 정해진 JSON 형식으로 받습니다. 기본 모델은 gpt-5.6-terra이고, 관리자 페이지에서 다른 모델로 바꿀 수 있습니다. 위기 상황 감지는 AI에 맡기지 않고 코드(키워드)로 직접 처리합니다.

AI가 맡는 일은 다음과 같습니다.

- 상황·맥락을 이해하고 요약하기
- 감정과 필요를 탐색하는 질문 만들기
- 자기수용 표현 제안하기
- 조절활동 제안하기
- 사용자가 수정하거나 거부한 내용을 이후 대화에 반영하기

## 데이터 관리

데이터베이스는 SQLite(aiosqlite)를 사용하며, 기록과 성찰일지는 암호화해서 저장합니다.

저장하는 데이터는 **사용자 동의 정보**, **대화 기록**, **성찰일지**, **사용 일시·횟수 기록**입니다.
